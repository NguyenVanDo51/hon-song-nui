Thành phần game

Mọi thành phần của Công Thành Chiến ở một chỗ, khớp 1-1 với game: hình, âm thanh, chữ, số liệu đọc thẳng từ code + file của game; ảnh màn hình chụp từ game thật. Chọn một trang:

Cập nhật

  • Đổi âm (công thức trong scripts/ui/audio.gd) → godot --headless --path . -s tools/bake_sfx.gd → godot --headless --path . -s tools/design_dump.gd
  • Đổi tướng / lính / màu / chữ / level / địa hình → godot --headless --path . -s tools/design_dump.gd
  • Đổi giao diện / hình → tools/design_shots.sh (≈ 5 phút, mở nhiều cửa sổ game, cần màn hình bật)
  • Quay lại cảnh có tiếng → tools/record_sfx_scene.sh m07 150 (≈ 2 phút)

Ảnh + cảnh quay nằm trong docs/design/shots/, docs/design/scene/ (git bỏ qua, mỗi máy tự sinh).

Dữ liệu sinh từ game: godot --headless --path . -s tools/design_dump.gd · ảnh: tools/design_shots.sh · cảnh có tiếng: tools/record_sfx_scene.sh m07 150. Không sửa tay trang này để đổi game: sửa game rồi chạy lại các lệnh trên.
