Đã làm
  • Da UI F1 · Truyện Kỵ Sĩ + font C (Paytone One): giấy da, viền mực 3 px, bóng cứng lệch, nút nhấn lún đúng chỗ bóng, panel khung đôi + hình thoi vàng, Hết lượt = dấu sáp đỏ in vương miện (lắc khi đã ra lệnh hết), băng rôn lượt đỏ (ta) / lam (địch), nền menu = trang giấy da có đồi khắc gỗ.
  • 22 hình quân mới + 12 rig đòn đánh (11 loại × 2 phe). Hình token sinh từ chính parts của rig (node tools/rig_export.mjs --svg) → token luôn khớp khung 0 của đòn đánh; phe địch tự đổi màu (đỏ→lam, vàng→bạc).
  • Chỉ huy tư thế B · cắm kiếm, đòn "Kiếm Giáng": nhổ kiếm → chém chéo → cắm lại. Golem Đá rig mới (song quyền giáng đất). Cung thủ (kéo cung), Tu sĩ ánh sáng (giơ đèn → nện chùy) sửa đòn; các quân khác giữ nhịp, đổi hình.
  • Công trình: lâu đài 2 tháp, làng mái rơm + cối xay, làng cháy, giếng thần, cầu gỗ.
  • Icon tự vẽ (25 SVG) thay emoji trên nút, HUD, dòng mục tiêu, ô dự báo đánh.
  • Chữ: tên quân / tướng / phe (Quân Khởi Nghĩa · Đế Quốc) / ô / chữ UI (lâu đài, làng cháy, giếng thần, tu sĩ ban phước…). Tên màn / chương / địa danh / tagline / credits / thoại giữ nguyên (theo anh chốt).
  • Âm thanh: nhạc nền D Dorian kiểu đàn lute + trống trận (thay ngũ cung đàn bầu); tiếng nút = dấu sáp, thắng = kèn, thua = kèn trầm, hào quang tu sĩ = chuông thánh, thêm tiếng lật giấy.
