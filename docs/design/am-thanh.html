Hiệu ứng tổng hợp bằng code (node tools/sfx/synth.mjs, kiểu "nhạc cụ gõ": chuông / mộc cầm giọng Rê + 1 phòng vang chung, cân âm lượng theo loại) thành assets/sfx/s_*.wav; âm hay lặp có 3 biến thể s_<âm>_1..3.wav, game phát ngẫu nhiên 1 cái. s_select.wav = âm cũ giữ lại.
