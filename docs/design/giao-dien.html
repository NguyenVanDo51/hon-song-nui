Màu

Mọi hằng màu trong scripts/ui/style.gd (giấy, mực, son, lá vàng, sơn mài…). Tên = tên hằng trong code.

Màu phe

content/theme.gd → factions: tô áo quân, viền, mái nhà, cờ lâu đài.

Font

File font game nhúng (assets/fonts/). Mẫu chữ hiển thị bằng chính file đó.

Icon

assets/ui/icons/*.svg, trên nền giấy và nền gỗ tối.

Emoji

assets/emoji/*.png: ảnh emoji game nhúng sẵn (để icon giống nhau trên mọi máy). Tên file = mã Unicode.

Nút, thẻ, popup

Kiểu nút / khung trong game do Style.make_theme() dựng bằng code (~20 kiểu nút: MenuBtn, PrimaryBtn, ActBtn, BackBtn, SegBtn…). Xem hình thật ở trang Màn hình. Gom kiểu nút đang nằm trong docs/TODO.md § Nợ kỹ thuật.

Dữ liệu sinh từ game: godot --headless --path . -s tools/design_dump.gd · ảnh: tools/design_shots.sh · cảnh có tiếng: tools/record_sfx_scene.sh m07 150. Không sửa tay trang này để đổi game: sửa game rồi chạy lại các lệnh trên.
