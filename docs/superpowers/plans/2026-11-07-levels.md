# Level Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** campaign w/ story + chapters -> numbered levels 1..N (unlock in order, tier Dễ/TB/Khó), level select grid, map generator + skill, 30–50 levels drawn (not yet sim-calibrated).

**Architecture:** levels = same `DEF` files as missions, moved to `content/levels/`, sorted by `order`. Old 16 missions keep their ids (`m01`…`m16`) -> saves / progress / stars / golden need no migration. Generated levels get ids `g01`, `g02`… (stable, order-independent); shown number = index in sorted list. Generator = pure static lib in `sim/` + SceneTree driver; reuses `sim/mapgen.gd` `relayout`.

**Tech Stack:** Godot 4.7.2, GDScript strict typing (warnings = errors), gdlint + gdscript-formatter (`tools/lint.sh`), headless tests `sim/tests.gd`, click driver `sim/click_driver.gd`.

**Spec:** `docs/superpowers/specs/2026-11-07-levels-design.md`

## Global Constraints
- **Never touch bot logic**: `scripts/core/ai.gd`, `scripts/core/ai_plan.gd`, `AI.DEFAULT` / `AI.PRESETS`, `ai_goals` / `ai_tile` hooks in `scripts/core/objectives.gd`. (user)
- Enemy bot per level: `"normal"` or `"hard"` only, never `"easy"`. (user)
- No sim-based calibration runs (balance sweeps) in this plan; only smoke runs (≤ 2 games) to prove code works. Calibration = later plan P2b after bot V2-hard. (user)
- No rule changes (`rules.gd`, combat in `game.gd`). No 3D.
- Run Godot only via `tools/run_guarded.sh <log> -- <args>` (memory/time guard). Windowed runs (click driver, shots) need the Mac display awake.
- Strict typing: read Dictionary fields into typed vars; no method calls on Variant. gdlint: lines ≤ 150; formatter must pass (`tools/lint.sh`).
- New `class_name` / new scripts -> `godot --headless --path . --import` (commit generated `.uid`).
- Commits: English, ultra-terse, end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never push; no remote. Never merge into `master` without user OK.
- Player-facing text Vietnamese. Menu label "Thử thách". Tier labels: `easy` "Dễ", `mid` "Trung bình", `hard` "Khó".
- Internal names kept to avoid save migration: `ctx.kind == "campaign"`, Store keys `campaign_done` / `campaign_stars`.

## Review Focus
1. Old save mid-mission (`ctx = {kind: "campaign", id: "m05"}`, maybe with stale `"story": true`) -> loads, continues, no overlay, no crash. Test in Task 1 + Task 4.
2. Player who already won m01–m16, then generated levels are inserted between them -> every level up to m16 open, not pushed back to the first new one. Test in Task 2.
3. Level with `ai: "hard"` saved + continued -> same bot (aiParams saved in state). Test in Task 2.
4. Winning the last level -> no "Level tiếp" button, select screen shows all done, no crash. Test (`Content.next_level`) in Task 3.
5. Every generated level passes the same content validator as hand-made ones (rows, passable spawn tiles, no overlap, objectives, stars bar). Test = existing "content valid: <id>" loop (Task 4) + `LevelGen.problems` (Task 6).

### Task 6: Generator library

**Files:**
- Create: `sim/levelgen_lib.gd` (`extends RefCounted`, static only; used via `const LevelGen := preload("res://sim/levelgen_lib.gd")`)
- Modify: `sim/tests.gd`

**Interfaces:**
- Consumes: `sim/mapgen.gd` `static func relayout(id: String, m: Dictionary) -> Array` (rows), `Game.new_game`, `Objectives.check`, `Stars.check_def`, `Rules.TERRAIN`.
- Produces:
  - Recipe (Dictionary): `id` String, `title` String, `order` int, `tier` String, `ai` String, `w` int, `h` int, `castles` {p: int, e: int}, `villages` int, `river` `"none"|"v"|"h"`, `bridges` int, `rough` float (~0.30), `temples` int (0–2), `sym` bool, `win` Dictionary (as DEF), `allowed` {p: Array, e: Array}, `gold` {p: int, e: int}, `start` {p: Array[String] unit types, e: Array[String]}, `waves` Array (`{ turn, units: [type…] }`), `night` bool, `unitCap` int, `stars` Dictionary, `newUnits` Array.
  - `static func build(recipe: Dictionary, seed: int) -> Dictionary` -> level DEF (all DEF keys + `gen: { recipe: id, seed }`), deterministic per seed; `{ "error": String }` when it cannot place everything.
  - `static func problems(def: Dictionary) -> Array[String]` -> [] when valid: row lengths == `w`, every tile known, units on passable + no overlap, `Objectives.check(Game.new_game(def)) == ""`, `Stars.check_def(def) == ""`, heavy (no-mountain) path joins every castle, `reach` goals reachable, `ai` in `Content.LEVEL_AI`, `tier` in `Content.TIERS`.
  - `static func metrics(def: Dictionary) -> Dictionary` -> `villages_near` {p, e} (villages closer to that side's castles/start), `balance` float (p share of near villages, 0.5 = even), `open_castles` int (castles with no rough/water tile within 2), `path_len` int (road distance between nearest opposing castles / starts).
  - `static func to_source(def: Dictionary) -> String` -> GDScript text `extends RefCounted\n\nconst DEF := {…}` in the style of `content/levels/m02.gd` (one `map.rows` string per line).
- Algorithm (builder's call, spec §16) must: place castles per side on opposite halves, villages spread by side-distance per `balance` target 0.5 ± 0.1 unless recipe skews, river + bridges, temples between sides off units / buildings, then `relayout` for roads + rough clumps; `sym` -> 180° symmetric.
