# Đa ngôn ngữ (2026-11-09)

Ngôn ngữ: **Tiếng Việt** (gốc) + **English**. Mặc định = ngôn ngữ máy nếu có (`vi`), không thì English. Người chơi đổi: nút **Ngôn ngữ** (VI / EN) ở màn tiêu đề + menu ⚙ trong trận -> lưu `Store "lang"`, tải lại scene (trong trận: lưu ván rồi vào lại đúng ván).

## Cách chạy
- Chữ gốc = tiếng Việt, viết thẳng trong code / nội dung. Bản dịch = gettext `locale/<mã>.po`, **msgid = đúng câu tiếng Việt** (`locale/messages.pot` = khuôn).
- `project.godot` `locale/fallback="vi"` (bắt buộc): không có catalog `vi` -> Godot rơi về ngôn ngữ dự phòng; để `en` thì chọn Tiếng Việt mà mọi Label / Button tự dịch vẫn ra tiếng Anh (lỗi 2026-11-09). Test `content.gd` "language: Vietnamese…" giữ.
- `scripts/core/lang.gd` (`Lang`): `Lang.t("...")` = 1 câu; `Lang.deep(dict)` = mọi chuỗi trong dict / mảng. `Lang.apply(code)` đổi `TranslationServer` locale + xoá cache `Content`.
- Nội dung (`content/theme.gd`, level, bản đồ đấu tự do): `Content.theme()` / `Content.levels()` cache **đã dịch** -> code đọc theme / level không cần gọi `Lang.t`.
- `content/guide.gd`, `Content.traits`, `tile_note`, tên vùng trên bản đồ vương quốc: dịch tại chỗ dùng (`Lang.t`).
- Chữ trong `scripts/`: **mọi** câu tiếng Việt phải nằm trong `Lang.t(...)` (cả câu có `%d` / `{x}`: dịch khuôn trước, điền số sau: `Lang.t("Lượt %d") % n`). Hằng (`const`) không gọi hàm được -> đánh dấu `i18n-const` + `Lang.t` ở chỗ dùng (`menus.gd OPPONENTS`, `level_select.gd TIER_NAME`).
- Control (Label, Button…) Godot tự dịch `text` khớp msgid, nhưng chữ vẽ thẳng (`draw_string`, `Draw.text_c`) và chữ ghép thì không -> luôn `Lang.t`.

## Thêm / sửa chữ
1. Viết câu tiếng Việt (trong `Lang.t(...)` nếu ở `scripts/`).
2. `python3 tools/i18n_extract.py` -> cập nhật `messages.pot` + thêm msgid mới vào mọi `.po` (msgstr rỗng).
3. Dịch các dòng `msgstr ""` trong `locale/en.po`. Giữ nguyên `%d` `%s` `{eh}` `[b]` `[color=#%s]`, khoảng trắng đầu / cuối.
4. `tools/lint.sh` chạy `i18n_extract.py --check`: fail nếu còn câu chưa dịch hoặc câu tiếng Việt trong `scripts/` nằm ngoài `Lang.t`.
- Sửa câu gốc = msgid mới -> bản dịch cũ mất (dòng cũ bị bỏ khi chạy lại) -> dịch lại.

## Kiểm
- Test (`sim/tests.gd`) + driver (`click_driver`, `tut_driver`, `design_driver`) ép `vi` (bấm nút theo chữ tiếng Việt); máy dev locale `en_VN` -> mặc định chạy game là English.
- `sim/lang_check.gd` (chạy trong `tools/lint.sh`, cả pre-commit khi commit đụng `project.godot` / `locale/` / `scripts/` / `content/`): khởi động 1 ngôn ngữ -> đổi sang ngôn ngữ kia như nút Ngôn ngữ -> mở tiêu đề, bản đồ level, đấu tự do, 1 đấu 1, Giới thiệu, Sách lính, trong trận, ⚙, màn kết thúc -> đọc chữ **đang hiện** của mọi Label / Button / RichTextLabel (`atr`). VI: không chữ nào ra tiếng Anh. EN: không còn câu tiếng Việt chưa dịch (trừ `KEEP` = tên game). Điểm mù: chữ vẽ thẳng (`draw_string`, bàn cờ, bản đồ) -> vẫn phải `Lang.t` + xem bằng mắt.
- Cờ debug `lang=vi|en`. Ảnh tiếng Anh: `SHOT_LANG=en tools/design_shots.sh screens|ui` -> `docs/design/man-hinh.html` nút English. Driver bấm chữ tiếng Việt nên chạy `lang=en` chỉ chụp được 1 phần bước.
- `docs/design/chu.html`: mọi chữ, cột Tiếng Việt + English, ô đỏ = chưa dịch.
