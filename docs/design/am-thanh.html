Âm thanh

Mọi âm thanh trong game đều là tiếng tổng hợp bằng code (sóng + nhiễu), dựng sẵn thành file assets/sfx/s_*.wav. Nút ▶ phát đúng file game đang dùng. Hình thanh ngang = các lớp của âm (thời gian → phải). "Nghe trong cảnh" nhảy tới lúc âm đó phát trong đoạn game thật bên dưới.

Cảnh game

Đoạn quay từ game thật (bot đấu bot, có cận cảnh đánh), hình và tiếng gốc. Mỗi vạch trên thanh thời gian = 1 lần phát âm thanh; tên âm hiện ở góc trái khi nó phát. Chọn một âm ở bên phải để chỉ xem vạch của nó, ‹ › để nhảy giữa các lần.
